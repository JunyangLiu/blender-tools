# 局部原网面重构 v1

## 当前模型数据约定

- 坐标框架：只使用当前语义源对象的局部坐标；候选继承源对象的世界变换。
- 绿色标记：实际需要细化平滑或平整的局部网面；按住左键拖动可连续刷选凹面。
- 红色标记：必须保持原位的排除面；选择“红色参考面”时，也提供平整法向，但红色面本身仍不会移动。
- 帆布波浪模式：绿色标记帆布本体；红色标记绑带、安装件、装甲、压紧边和不得改变的真实边界。至少需要 3 处沿长度与宽度分散的绿色标记。
- 区域范围：只处理刷到的同源网面。磁吸半径只帮助鼠标命中，不会扩大重构范围，也不会扫描其他对象或整车。

## 默认阈值与保护

- 局部细化等级：1（最多允许 2）。
- 平滑强度：0.22，单顶点位移按局部中位边长限制。
- 硬边保护角：35°。
- 区域边界、硬边及红色保留面边界上的顶点不移动。
- 一键平整按每个连续标记区分别拟合；高度可选最低点、中位或最高点，法向可选自动拟合、第一处绿色面或红色参考面，不套用对象 XYZ 轴，也不复用其他车辆数据。
- 断开的低支撑小碎片（少于 3 个内部可移动顶点）保持原样，不参与主区域的平整进度与安全回退；报告会列出保留数量和面数，主区域仍必须独立通过翻面、退化和进度质量门。
- 外边界与红色面始终锁定；投影采用逐步回退，并拒绝翻面或退化三角形，避免局部表面错乱。

## 帆布波浪重建

- 只对当前语义源的绿色面计算，不搜索车体其余网格。
- 从绿色区域本身做局部 PCA，得到帆布长轴、横向轴和表面法向；不会套用世界轴或其他车辆的数据。
- 先用低阶曲面分离源模型的大尺度下垂和折叠，再从剩余高度中拟合周期、相位和二次谐波。若源波纹证据过弱，则使用绿色区域边界作为确定性相位锚点，绝不加入随机位移。
- 只轻微软化低模三角面；硬边、大褶皱、绿色外边界和红色锁定面保持不动。生成波纹在 3 圈拓扑距离内平滑衰减到零。
- 波纹振幅上限为局部中位边长的 14%，总位移另有局部尺度上限；滑块只控制波纹程度，不暴露波长、相位等技术参数。
- 平滑与波浪完成后，使用同一份局部细分参数化逐点比较候选与原绿色网面；沿当前标记区拟合出的外侧法向，计算“刚好覆盖全部原凸面”所需的最小整体外移量。允许候选位于原模型外侧，但外移量受局部尺度上限约束，绿色外边界仍锁定，不靠猜测微调，也不扫描全车。
- 候选报告记录局部坐标框架、波长、振幅、来源拟合度、密集顶点源距离、外侧覆盖检查和“未扫描全车”证明。

## 验收与替换

### 多折面帆布优化（独立入口）

- 原“帆布波浪重建”入口与算法保持不变；多折面帆布使用独立模式，避免后续调整影响已认可效果。
- 只读取当前语义源上的绿色标记面、绿色边界和局部折脊，不扫描整车或其他对象。
- 先按自适应折角识别连续折脊，过滤孤立的三角剖分斜边；折脊与绿色边界的交点作为悬挂/绳侧锚点证据。
- 细分后只沿保存的源法向做双边微面消噪，不做大尺度整体公平化；连续折脊、布片轮廓、红色面和绿色外边界保持锁定，避免出现橡皮泥感。
- 多折面候选使用细分后的细面显示而不是强制全平滑高光，让纤薄褶皱在验收和最终替换后都保持可读。
- 皱褶在悬挂锚点附近更密、更明显，并向布片内部连续衰减；不使用随机噪声，不复用其他车辆的坐标、尺度或阈值。
- 完整变形必须通过回退式翻面、退化和同批折角检查，并继续通过局部源距离与外侧覆盖门槛；失败只拒绝新候选，不修改源网格。


- 候选必须保持源对象指纹不变、不得增加无连接边或非流形边、不得增加边界连通分量。
- 内区折角样本足够时，95% 分位折角不得比重构前恶化超过 2°；平整模式还要求全局部区域的平面 RMS 下降。
- 帆布模式允许波纹造成的局部折角变化，但 95% 分位增量仍不得超过 8°，且所有绿色内部顶点必须通过源距离、翻面和退化检查。
- 帆布候选还必须通过外侧包络门槛：可移动顶点不得落在对应原网面内侧；若计算出的必要外移量超过局部安全上限，则拒绝生成，不输出部分覆盖候选。
- 可见橙色半透明补片只显示受影响区域；完整工作网格单独保留，源车始终可见。
- 候选生成期间仅暂时隐藏本轮绿色/红色标记辅助，避免颜色层遮挡重建效果；移除候选时恢复标记，确认候选时再随本轮记录一起清除。
- “确认替换原网面并清除标记”只交换源对象的网格数据，保持对象身份；旧网格进入恢复归档，并保留确认前 `.blend` 检查点。
