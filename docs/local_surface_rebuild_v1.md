# 局部原网面重构 v1

## 当前模型数据约定

- 坐标框架：只使用当前语义源对象的局部坐标；候选继承源对象的世界变换。
- 绿色标记：实际需要细化平滑或平整的局部网面；按住左键拖动可连续刷选凹面。
- 红色标记：必须保持原位的排除面；选择“红色参考面”时，也提供平整法向，但红色面本身仍不会移动。
- 区域范围：只处理刷到的同源网面。磁吸半径只帮助鼠标命中，不会扩大重构范围，也不会扫描其他对象或整车。

## 默认阈值与保护

- 局部细化等级：1（最多允许 2）。
- 平滑强度：0.22，单顶点位移按局部中位边长限制。
- 硬边保护角：35°。
- 区域边界、硬边及红色保留面边界上的顶点不移动。
- 一键平整按每个连续标记区分别拟合；高度可选最低点、中位或最高点，法向可选自动拟合、第一处绿色面或红色参考面，不套用对象 XYZ 轴，也不复用其他车辆数据。
- 外边界与红色面始终锁定；投影采用逐步回退，并拒绝翻面或退化三角形，避免局部表面错乱。

## 验收与替换

- 候选必须保持源对象指纹不变、不得增加无连接边或非流形边、不得增加边界连通分量。
- 内区折角样本足够时，95% 分位折角不得比重构前恶化超过 2°；平整模式还要求全局部区域的平面 RMS 下降。
- 可见橙色半透明补片只显示受影响区域；完整工作网格单独保留，源车始终可见。
- “确认替换原网面并清除标记”只交换源对象的网格数据，保持对象身份；旧网格进入恢复归档，并保留确认前 `.blend` 检查点。
