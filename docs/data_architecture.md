# 语义标记数据架构 v2

## 四层模型

1. **文档**：一个 Blender 场景对应一个稳定 `document_id`、修订号和全局递增标记编号。
2. **任务**：隔离不同处理意图、语义源快照、状态和统计。当前默认任务为 `task-0001`。
3. **标记**：记录角色、可视辅助对象、命中对象、语义源、时间、置信度和扩展字段。
4. **表面锚点**：保存面编号、世界/局部坐标与法线、源网格指纹；三角面额外保存顶点编号和重心坐标。

## 场景存储

- `smrn_document_json`：小型索引，只含任务摘要、计数、块列表和版本信息。
- `smrn_marks_chunk_XXXXXX_json`：标记数据块，每块最多 128 条。
- `smrn_surface_index_XX_json`：256 路散列去重桶，点击时只读取一个桶。
- `smrn_marks_json`：v1 旧数据。首次读取时自动迁移，但原属性保留用于回退。

新增标记只写末尾数据块、一个去重桶和小型文档索引。侧栏只读取文档索引，不遍历全部标记。

## 扩展边界

当前界面只开放 `target` 与 `exclude`。底层预留 `boundary`、`attachment`、`gap_start`、`gap_end`、`axis`、`centerline` 和 `reference`；第三方角色必须使用 `x.` 命名空间。未知未来数据放入 `extensions`，避免无版本字段散落。

锚点绑定实际命中网格，任务源快照描述完整语义源；两者分离以支持复杂模型的子对象。显示尺寸 `semantic_radius` 与几何处理阈值分离；可视标记仍是不可导出的辅助对象，不能成为射线命中对象或修改源网格。

已有局部锚点不会在网格发生变化后被静默重算；保存的指纹用于后续检测源网格漂移，再由明确的重绑定流程处理。
