# 平整组件隔离安全策略 v2

## 目标

绿色刷选可能包含互不连通的细条、漏刷形成的小岛或只有极少内部顶点的碎片。
这些弱区域不能再与主要连续区域共用一次全局回退和一次全局折角否决。

## 当前行为

- 只读取当前语义源上的绿色与红色标记，不扫描整车或其他对象。
- 按受保护边界把绿色区域拆成独立连通组件。
- 每个组件独立拟合、试投影、检查翻面、退化与同批折角。
- 折角样本不少于 32 条边的主组件采用稳定的 95% 分位统计；样本不足的小岛保持严格限制。
- 能安全完成至少 75% 投影并把平面 RMS 降至原值 25% 以内的组件才进入候选。
- 低支撑或无法有效安全投影的小组件保持原样，不得否决已通过的主组件。
- 全局仍检查非流形边、边界连通块、翻面、退化与最大位移。
- 重复点击同一请求直接复用现有候选，并同步最新报告状态。

- 当前语义源：`turret_v96_with_rear_drum_L_selectable`
