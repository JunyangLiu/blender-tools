# 扶手 / 把手还原 v1

## 标记语义

- 绿色：同一个扶手的管体表面，尽量覆盖左右腿、转角和顶部。
- 红色：扶手左右两端各自的安装面。红色不是“删除区”，在本功能中只作为安装约束。
- 每轮只处理一个扶手；标记、坐标和阈值只属于当前模型，不复用其他车辆数据。

## 与旧算法的关键区别

旧实现会先在一个坐标系中拟合跨度、基线和高度，再用安装面切线替换坐标轴。标注角度虽然会变成零，但原来拟合出的标量并没有随坐标系一起重新计算，因而会造成扶手角度、端点和高度漂移。

新实现先由绿色管体与红色双端安装面共同确定最终坐标框架，再在该框架内一次性拟合路径。安装面法线只决定“向外”的高度符号，反向法线不会把扶手翻进车体。

## 路径和截面

- 路径候选为半椭圆，或带直腿、相切圆角和严格直顶段的平顶扶手。
- 根据源表面法线回缩得到管体中心证据。
- 安装桥/端脚参与端点连接判断，但不参与管径估计，避免宽安装片把管径撑大。
- 法向半径与中面内半径分别测量，再以最小比例扩张椭圆截面，要求保留的密集管体样本零遗漏。
- 左右端分别读取红色安装面深度，并把候选中心线埋入安装面，不能用单端证据代替另一端。

## 生成门槛

- 至少 7 个绿色样本、2 个红色样本，且红色必须分别约束左右端。
- 安装切线与绿色扶手主跨方向差不超过 28 度。
- 鲁棒管体走廊保留率至少 80%，排除安装桥后管体密集样本至少占 55%。
- 候选必须是一个封闭连通体，边界边和非流形边均为 0。
- 生成前建立新的 `.blend` 检查点；源网格指纹必须保持不变，源车体始终可见。

候选只用于检查。用户完成视觉验收前，不替换、不布尔合并源模型。
