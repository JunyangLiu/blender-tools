# 圆柱 / 圆锥圆润候选 v1

## 设计目标

本功能只解决“当前目标标记能够证明的旋转曲面”。它不猜测隐藏整圈，不依赖车辆坐标或旧任务的面编号，也不直接修改源模型。

## 输入与坐标

- 输入只来自当前任务、同一语义源上的目标点、表面法线和排除点。
- 每次运行都重新校验源网格指纹，并从当前点与法线统计推断轴线。
- 候选轴来自点云协方差、法线协方差和法线差分；不添加物体或世界 XYZ 轴候选。
- 标记面顶点只用于扩大候选的轴向和角度边界，不参与捏造整圈证据。

## 拟合

对每个数据导出的候选轴，把点和法线投影到垂直于轴的平面，使用 Huber 迭代重加权求解：

`点投影 = 轴心 + (有符号半径 + 斜率 × 轴向位置) × 法线径向分量`

- 有符号半径为正表示外凸面，为负表示内凹面。
- 圆锥只有在相对圆柱的拟合改善足够、轴向跨度足够且轮廓变化高于噪声时才成立。
- 整圈由最大角度缺口与其余采样步长比较决定；闭合证据不足时只能是局部弧。
- 对轴向很窄但覆盖超过半圈的圆周标记，使用当前点云平面的法线确定轴线，再由各点表面法线估算圆锥斜率。该路径仍保留实际角度缺口，不把部分圆周补成整圈。

## 默认质量门槛

- 至少 4 个当前源表面样本。
- 点残差 P90 / 中位半径不大于 0.22。
- 法线误差 P90 不大于 28°。
- 线性系统条件数不大于 250。
- 可证明的圆周跨度不小于 12°。
- 圆锥还需满足最小轴向比例、至少 12% 的得分改善，并让轮廓变化超过噪声 2.5 倍。

门槛与具体车辆坐标、尺寸和面编号无关。

## 候选与 QA

- 候选放入独立候选集合，默认 128 圆周细分，局部弧按角度比例缩减。
- 外凸候选只向外增加余量；内凹候选只向孔内增加余量，厚度放在材料侧。
- 使用标记三角面的密集重心采样检查外覆盖。
- 排除标记落入候选包络时拒绝生成。
- 每条候选边必须恰好属于两个面；同时检查坐标有限性。
- 通过所有门槛后才建立源 `.blend` 检查点并生成候选。源对象不被替换、隐藏或保存覆盖。
- 新候选先完整通过可见性与场景提交检查，再删除旧候选；提交失败时回滚新对象并保留上一个可用候选。

## 当前限制

- 一组标记只支持一个旋转曲面；跨零件或跨语义源会拒绝。
- 法线混乱、近似平面、过窄圆弧或点位虽连续但不符合共同轴线时会要求补充/重新标记。
- v1 不做候选与源网格的布尔合并，也不自动删除旧结构；验收替换属于后续独立功能。
