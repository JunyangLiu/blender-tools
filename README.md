# Semantic Mesh Restorer Next

语义网格修复插件的逐功能重构工程。当前版本提供稳定的语义标记数据层、非破坏式“圆柱 / 圆锥圆润候选”，以及可由绿色管体自动推断双端安装、也可用红色安装面纠偏的扶手 / 把手还原候选。

## 已完成

- 在所有可见网格上建立绿色目标标记和红色排除标记，不隐藏或改写源网格。
- 使用版本化的“文档 → 任务 → 标记 → 稳定表面锚点”数据模型；记录分块保存，侧栏只读取轻量统计。
- 只使用本轮标记点与法线推断旋转轴，不注入物体 XYZ 轴或其他车辆的尺寸。
- 使用鲁棒的有符号半径拟合区分外凸表面与内凹孔，并以可测量的轴向轮廓变化区分圆柱和圆锥。
- 只有角度闭合证据充分时才允许整圈；否则生成局部弧候选，证据不足则明确拒绝。
- 候选为独立、封闭、可移除的壳体；生成前建立 `.blend` 检查点，源网格始终可见且拓扑不变。
- 生成门槛包括：拟合误差、法线一致性、数值条件、密集外覆盖、排除标记冲突和非流形边检查。
- 扶手先锁定最终安装坐标框架，再拟合跨度、基线和高度，修复旧版“拟合后换轴”导致的角度与端点漂移。
- 扶手支持半椭圆和平顶直段路径；默认从管体自动推断双端埋入，红色安装面仅用于纠偏，安装桥和少量截面离群点不再撑大管径。

尚未迁移：区域生长、缺口路径、边界 / 安装点约束、自由形重建、通用加厚和平滑，以及候选验收替换。

## 使用

1. 在 Blender 安装 `dist/semantic_mesh_marker_next.zip`。
2. 从 3D 视图右侧栏打开“语义标记 Next”。
3. 设定当前语义源，用绿色标记覆盖同一段圆柱或圆锥表面；必要时用红色标记保护邻近结构。
4. 先点“分析圆柱 / 圆锥证据”。通过后再点“生成圆润候选”。
5. 检查蓝色线框候选、源模型上下文和报告；用户验收前不会替换源网格。
6. 扶手功能中，只需用绿色标记一个扶手的管体；如自动安装方向不准，再用红色分别标记左右安装面纠偏。随后生成橙色线框候选。

## 目录

- `blender_addon/semantic_mesh_marker_next/`：Blender 插件源码。
- `docs/data_architecture.md`：基础数据模型。
- `docs/rotational_surface_v1.md`：新旋转曲面算法、门槛和限制。
- `docs/handle_restoration_v1.md`：扶手路径、安装角、截面和质量门槛。
- `tests/`：不依赖 Blender 的记录、存储和数学回归测试。
- `scripts/build_addon.ps1`：生成可安装 ZIP。
